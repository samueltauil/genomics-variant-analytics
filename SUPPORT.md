# Support

## Support expectations

This repository is a demo accelerator and reference architecture. It is provided
as-is, with **no support commitment, response-time commitment, or service-level
agreement (SLA)**.

This accelerator is not a supported Microsoft offering, product, service, or
released blueprint. Opening an issue here does not create a Microsoft support request and
does not provide access to Microsoft product support.

## Reporting a defect

If a repository defect blocks preparation or delivery of the demo, report it by
[opening a GitHub issue](https://github.com/samueltauil/genomics-variant-analytics/issues/new).
Include:

- The commit SHA or release tag you used.
- The affected phase: preflight, provisioning, seeding, presentation, reset, or
  teardown.
- The relevant spec or runbook step and what you expected to happen.
- What happened instead, including the missing or unexpected observable result.
- Minimal reproduction steps.
- Sanitized error messages or logs.
- The Azure region and subscription type, without tenant IDs, subscription IDs,
  resource names, hostnames, account identifiers, or other environment-specific
  identifiers.
- Whether the defect blocked a planned customer delivery.

Do **not** include protected health information (PHI), patient-identifiable
information, genomic data or files, credentials, access tokens, storage keys,
connection strings, or other secrets. Redact sensitive and environment-specific
values before attaching logs, screenshots, or configuration excerpts.

Issues are reviewed on a best-effort basis. Submission does not guarantee a
response, resolution, fix schedule, or release.
